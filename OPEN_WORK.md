# envlib ingestion — Open Work

The **datasets/ingestion track** of the envlib project: this toolkit, the per-source ingest
repos (`envlib-ingest-*`), dataset selection/licensing, and the tethys→envlib data migration.
Stack *development* (envlib/cfdb/ebooklet package work) is tracked separately in
`envlib-repos/envlib/OPEN_WORK.md`. Same conventions: **verification debts** (work done but
not yet proven; remove once the close-check passes) + **backlog**; completed items move to
**`OPEN_WORK_DONE.md`** (newest first). Sessions always launch from the envlib hub repo regardless of track.
